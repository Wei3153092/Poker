# 視窗程式設計 (II) - 上課練習_五張撲克牌

## 專案簡介
本專案實作了經典的「五張撲克牌」遊戲。除提供基本的洗牌、發牌、換牌與牌型判斷功能外，本次主要新增了**下注系統**。玩家可於遊戲開始前輸入押注金額，程式會自動扣除資金，並於最終判斷牌型時，根據牌型對應的賠率計算並發放獎金。

## 實作功能
* **基本流程**：發牌 -> 點擊牌面蓋牌 (選擇換牌) -> 換牌 -> 判斷牌型。
* **下注系統**：
  * 玩家起始總資金為 1,000,000 元。
  * 可自訂押注金額 (預設 500 元)，防呆機制包含防重複押注、防資金不足。
* **獎金結算**：內建賠率表 (皇家同花順 250倍 ~ 一對 1倍)，結算後自動加回總資金並跳出提示視窗。
* **開發者測試鍵 (快捷鍵)**：於發牌前按下 `q`, `w`, `e`, `r`, `t`, `y` 可直接測試特定中獎牌型 (如皇家同花順、同花順、四條等)。

## 執行說明
1. 開啟本專案的 Visual Studio 方案檔 (`.sln`)。
2. 點擊「啟動」或按 `F5` 執行程式。
3. 在下方「下注」區塊輸入押注金額，並點擊**「押注」**。
4. 點擊**「發牌」**。
5. (選擇性) 點擊不要的牌使其蓋下，接著點擊**「換牌」**。
6. 點擊**「判斷牌型」**，查看結果與獲得的獎金。
